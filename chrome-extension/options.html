How to use

  1. Right-click any link → “Download with SuperIDM”.
  2. Hover a video and press the SuperIDM pill, or right-click → “Download this media”.
  3. Toolbar icon lists everything on the current page, including HLS streams.
  4. Alt+S grabs the main media of the current page.
  5. Downloads are taken over automatically when that option is on.

SuperIDM must be running for the extension to do anything: it hands work to the desktop app, it is not a downloader by itself.
